# ShopKZ — обновлённый интернет-магазин

Сохранён исходный стек: Node.js + Express + SQLite, обычные HTML/CSS/JavaScript.
Это настоящий проект из RAR-архива, а не Python-модуль практик 7–8.

## Запуск в Windows и VS Code

1. Установите Node.js 24 LTS (нужна версия Node.js не ниже 22).
2. Распакуйте архив. Откройте **File → Open Folder → ShopKZ_Modern**.
3. Откройте **Terminal → New Terminal**. Рядом должны находиться package.json и server.js.
4. Выполните:

```powershell
npm ci
npm start
```

5. Откройте **http://localhost:3000**. Нельзя запускать index.html двойным щелчком: интерфейсу нужен API.
6. Остановка сервера: **Ctrl + C**.

База shopkz.db создастся автоматически при первом запуске. В архиве нет пользовательской базы и node_modules.
Если переносите существующую базу, сначала сделайте резервную копию shopkz.db при остановленном сервере.
Товары, аккаунты и заказы при обычном перезапуске сохраняются. Автоматически заменяются только первоначальные picsum-заглушки 12 учебных товаров. Пользовательские изображения не заменяются.

## Как пользоваться

Тема находится справа в шапке; на телефоне — справа в верхней зелёной строке.
Каталог доступен по кнопке «Каталог» или «Найти своё».
Сердце сохраняет товар, значок столбцов добавляет к сравнению.
Гостевая корзина сохраняется в этом браузере. Для оформления нужен вход — как в исходном проекте.
У зарегистрированного пользователя заказы и выход доступны в строке навигации под поиском; на узком экране её можно прокрутить.

## Оплата и расчёты

Сохранены расчёты JavaScript-проекта: сумма товаров минус процент действующего промокода; отдельного тарифа доставки в исходном API нет, поэтому в интерфейсе доставка в демо равна 0 ₸.
Python-правило бесплатной доставки от 20 000 ₸ из другого учебного архива здесь не подключено.

Заказ действительно записывается в локальную SQLite, но платёж и доставка — демонстрационные. Деньги не списываются, письма не отправляются.
Используйте только тестовую карту 4532 0151 1283 0366, срок 12/29, CVV 123.
Для демонстрации отказа сохранена карта 4000 0000 0000 0002. Настоящие реквизиты не вводите.
Тестовые промокоды исходного проекта: SALE10 и WELCOME15.

## Проверки

```powershell
npm run check
npm test
npm run test:system
```

В выполненной проверке:
- синтаксис JavaScript: успешно;
- Jest: **49 passed**, 5 suites (41 исходный тест + 8 новых проверок интерфейсной логики);
- системные HTTP-сценарии: **8 passed**;
- браузер: поиск, фильтры, гостевая корзина, избранное, сравнение, темы, история просмотров, zoom и Escape проверены вручную автоматизированным браузером;
- ширины 360, 390, 768, 1024, 1440: горизонтальная прокрутка страницы не обнаружена.

Логи находятся в verification, скриншоты — в verification/screenshots.
Отдельного production build нет: Express раздаёт public напрямую. npm run check проверяет синтаксис, это не ESLint.

Сохранены и обновлены Playwright E2E-сценарии; добавлены проверки адаптивности. Для самостоятельного запуска:

```powershell
npx playwright install chromium
npm run test:e2e
```

Полный Playwright runner в этой среде не запускался. Авторизованное оформление проверено системными HTTP-тестами; браузерные проверки выполнены для гостевых сценариев. Не путайте эти уровни тестирования.

## Внешние подключения

Реальные платежи потребуют платёжного провайдера и серверной интеграции. Email — почтового сервиса. Настоящие сроки и тарифы доставки — подключения перевозчика либо собственных правил. Эти интеграции не имитируются как работающие.
Интерфейс остаётся русскоязычным: неполный переключатель RU/KZ не добавлен.
Для публичной эксплуатации нужны отдельная настройка хостинга, HTTPS, секретов и production-хранилища сессий. Этот архив предназначен для локального учебного запуска.
