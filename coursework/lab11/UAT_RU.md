Технический dry-run: pytest 14/14, Bruno 5/5, E2E 9/9 в Actions ЗС10. Это проверка готовности, не подтверждение приемки другой командой.

Протокол для заполнения: фактическая дата, ФИО и команда заказчика, commit SHA, URL стенда, результат каждого сценария pass/fail/blocked, замечание и issue ID, решение принять/условно принять/отклонить. P0 блокирует запуск, P1 блокирует критический путь, P2 допускается только с владельцем и сроком. Внешняя сессия отслеживается issue #32.
