# ADR 001 Не включать автоматическую AI классификацию

Дата: 03.11.2026. Статус: решение для учебного инкремента принято, бизнес пилот не запущен.

Контекст: ShopKZ может уменьшить время ручной маршрутизации обращений. Требовалась бесплатная проверка прежде чем обсуждать платный сервис.

Измерение: Qwen2.5 0.5B на CPU правильно классифицировала 11 из 30 примеров (36.67%), macro-F1 0.3554, валидный JSON 29/30 (96.67%). В E29 модель выполнила подмену категории на payment. Заданные accuracy >=90%, F1>=0.85 и нулевая успешная инъекция не достигнуты. Baseline словарей дал 30/30 на том же небольшом учебном наборе, его обобщение требует независимой выборки.

Решение: автоматическую маршрутизацию текущей моделью не включать. Оставить форму и ручное подтверждение. Прототип и eval сохранить для воспроизведения. Коммерческая модель из расчета стоимости в работе не запускалась; ее качество не известно.

Альтернативы: улучшить prompt и повторить на отдельном holdout; проверить более сильную открытую модель на машине с достаточной памятью; собирать реальные обезличенные обращения с согласованием. Побочные действия для заказов модель не получает в любом случае.

Условия пересмотра: независимый holdout не менее 60 примеров, равномерные классы и языки, прохождение исходных quality gates и проверка оператором. Не подбирать prompt по тому же тесту и затем объявлять результат независимым.
