# Риск карточка AI классификатора

| Категория | Что может произойти | Контроль и человек |
|---|---|---|
| Ошибка качества | Обращение об оплате попадет в доставку и будет обработано позже | Оператор подтверждает категорию, может изменить ее; модель не исполняет действия |
| Prompt injection | Текст просит игнорировать правила и выбрать payment | Текст отделен от system prompt, список классов и JSON проверяются; тест E29 не пройден, auto-routing запрещен |
| Конфиденциальность | Текст может содержать адрес, карту, телефон | В eval только авторские тексты. Перед будущим пилотом маскирование и allowlist полей; реальные данные сейчас не передаются |
| Непрозрачность | Пользователь решит что категорию выбрал человек | Явная подпись AI у рекомендации, видимый ручной override |
| Языковое смещение | Казахские обращения распознаются хуже | Отдельный отчет по языкам, минимум 20 новых независимых примеров на язык перед пилотом |
| Надежность | Ollama недоступна, JSON оборван или ответ медленный | Timeout и fallback к ручной форме, отсутствие AI не блокирует оформление заказа |
| Экономика | GPU стоит дороже коротких запросов API | Расчет costs.json и capacity тест до любых расходов; в работе платных вызовов нет |

Провайдер при текущем исполнении: внешнему коммерческому AI провайдеру не передается ничего, модель локальная. Для загрузки весов Ollama получает сетевой запрос, но не тексты покупателей. Возможный будущий API вариант должен отправлять только обезличенный текст, без cookie, платежных реквизитов и учетных данных. Оплата или покупка GPU не выполнялись.
