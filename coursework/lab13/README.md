# PM ассистент ShopKZ

Запуск: `ollama serve`, `ollama pull qwen2.5:0.5b`, `python coursework/lab13/pm_assistant.py`.
Локально Ollama: 127.0.0.1:11434. GH_TOKEN хранится только в переменной окружения. Без токена работает чтение открытого репозитория с меньшим rate limit. Для воспроизведения сохраненного snapshot: `--replay`.

Выход: два черновика, исходные ответы, facts.json и generation_timing.json. Периоды 06–19.10 и 20.10–02.11.2026 являются ретроспективными 14-дневными окнами. Формальные идентификаторы прошлых спринтов не предоставлены. created_at/closed_at не восстанавливает reopen, а изменение label не считается завершением задачи. Поэтому open_at_end помечен как предварительная реконструкция.

Перед публикацией человек сверяет каждое число, завершения, участников, сроки, бюджет и выводы с источниками; исправляет raw draft в отдельном reviewed файле. Скрипт не отправляет сообщения, не меняет задачи и не публикует отчеты автоматически. При ошибке API или модели процесс останавливается, неизвестное не заменяется нулем.

Передавать в модель запрещено: токены, cookie, пароли, содержимое .env, данные карт, адреса/телефоны покупателей, тексты частных обращений, персональные сведения сотрудников и закрытые коммерческие условия. В текущем запуске модель локальная, ей передаются только счетчики, публичные заголовки и SHA. Заголовки issues являются недоверенным текстом, а не командами.

Workflow запланирован на понедельник 04:00 UTC. Он начнет исполняться по cron после слияния в default branch. Публикуется artifact, а не сообщение другим людям. До слияния в main расписание не считается активным.
