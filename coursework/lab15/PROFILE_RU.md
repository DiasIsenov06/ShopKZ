# Черновик профессионального профиля

Заголовок: Студент информационных систем | Учебные проекты по QA и управлению IT-проектами

О себе: Изучаю тестирование и управление разработкой на примере учебного интернет-магазина ShopKZ. В проекте подготовлены автоматические проверки, GitHub Actions, стратегия UAT, анализ инцидента и дашборды. Могу объяснить связь требований, тестов и критериев приемки, а также ограничения фактических данных. Интересуюсь начальными позициями в QA и проектной координации.

Проект: ShopKZ, учебный проект, октябрь–ноябрь 2026. Node.js, Express, SQLite, Jest, Supertest, Playwright, pytest, Bruno, Locust, GitHub Actions, Python, Ollama. Подготовка выполнена с использованием AI-ассистента. Коммерческий опыт и внешняя приемка не заявляются.

Публикация профиля не выполнялась. Перед размещением проверить формулировки навыков и добавить реальные контакты. Не помещать токены, данные покупателей и пароли демо аккаунтов.
