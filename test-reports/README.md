# Отчёты о реальных прогонах тестов

Эти файлы — не шаблоны, а сохранённый вывод терминала с настоящих запусков тестов
против кода этого проекта. Можете использовать их как доказательство выполнения
для практической работы, либо просто как ориентир, каким должен быть результат,
когда вы прогоните тесты у себя.

| Файл | Что внутри |
|---|---|
| `01_unit_tests.txt` | Прогон `npm run test:unit` — 21/21 passed |
| `02_integration_tests_BEFORE_FIX.txt` | Integration-тесты **до** исправления дефекта D-01 — 1 тест падает (это и есть момент обнаружения бага) |
| `03_unit_and_integration_AFTER_FIX.txt` | Те же тесты **после** исправления D-01/D-02/D-03 — все 36 зелёные |
| `04_acceptance_tests.txt` | Прогон `npm run test:acceptance` — 5/5 passed |
| `05_system_test.txt` | Прогон `npm run test:system` — 8/8 passed (реальный отдельный процесс сервера) |
| `06_coverage_report.txt` | Вывод `npm run test:coverage` — покрытие по `utils.js` (100%) и `server.js` (~55%) |
| `07_defects_log.md` | Журнал дефектов с severity, шагами воспроизведения и статусом исправления |

Хотите обновить эти файлы своими, свежими результатами — просто перезапустите
соответствующую команду и перенаправьте вывод в файл, например:

```bash
npm run test:unit > test-reports/01_unit_tests.txt
```
